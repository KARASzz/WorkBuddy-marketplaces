# 投标结果字段规范（复盘录入用）

投标结果公布后，引导用户按以下字段提供信息。未提供的字段标注"待补充"，严禁编造。

## 必填字段

| 字段 | 说明 | 示例 |
|------|------|------|
| 项目名称 | 本次投标项目全称 | XX 市供水管网改造工程 PE 管材采购 |
| 招标编号 | 招标文件编号 | HN-2026-XXX |
| 投标日期 | 递交投标文件日期 | 2026-XX-XX |
| 中标结果 | 中标 / 未中标 / 入围 / 废标 | 未中标 |
| 己方报价 | 我方投标总价（万元） | 586.0 |
| 中标价 | 中标方价格（万元，如公布） | 552.3 |

## 建议字段（能拿到就填）

| 字段 | 说明 |
|------|------|
| 各项得分 | 按评分办法分项得分（商务/技术/价格） |
| 排名 | 我方在所有投标人中的名次 |
| 竞争对手 | 中标方及主要竞争方名称 |
| 评审意见 | 评标委员会反馈（如有） |
| 失分点 | 自评或获知的失分环节 |
| 价格偏差率 | (己方报价-中标价)/中标价 |

## 复盘归档要求

- 每个项目一条记录，字段齐全度纳入复盘报告质量评估
- 结果字段与复盘报告一并存入复盘档案库，供后续累计分析（如：价格分占比高的项目应如何定价、技术分失分高发点）
