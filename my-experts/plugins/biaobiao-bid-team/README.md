# 标标·亚大投标专家团

面向海宁亚大塑料管道系统有限公司投标人侧工作的 WorkBuddy 专家团。主理人“标标”统一接收用户任务，并调度研标、素材证据、管道技术标、商务报价和独立终审五个成员。

## 设计特点

- 全流程 Markdown：中间阶段不反复生成 Word，人工终审通过后才由 WorkBuddy 统一生成终稿。
- 四道人工门禁：研标、策略与证据、分册、独立终审均需明确批准。
- 原始证据优先：资质、业绩、报价、技术参数等禁止推测填写。
- 版本可恢复：补遗、澄清或关键证据变化会使受影响的批准状态失效。
- 写审分离：独立终审官不参与初稿撰写。
- 项目知识闭环：结果公布后回写复盘档案、失分教训和评分规律。
- 保密优先：无必选 MCP、连接器、脚本或外部云端解析依赖。

## 团队成员

| 成员 | 职责 |
|---|---|
| 标标 | 主理人、项目状态、门禁、最终生成、复盘主持 |
| 研标官 | 招标文件、补遗、资格、评分、否决和格式要求解析 |
| 素材证据官 | 公司资料核验、证据链、投标策略、素材缺口与知识回写 |
| 管道技术标专家 | PE/PPR/PVC 技术响应、制造质控、供货、施工和服务方案 |
| 商务报价专家 | 商务响应、业绩编排、价格表结构与算术校核 |
| 独立终审官 | 响应性、证据、一致性、格式和递交条件终审 |

## 安装与复验

在 WorkBuddy 中导入本目录或发布压缩包。若本机安装了 WorkBuddy CLI，可在导入前执行：

```bash
codebuddy plugin validate /path/to/biaobiao-bid-team
```

专家包不包含业务执行代码。Word 由 WorkBuddy 在最终人工门禁通过后，依据已批准 Markdown 集合生成。

## 配套项目指令

工作区根目录的 `WorkBuddy-项目系统指令-升级版.md` 用于项目级共享事实、资料路径、安全权限和调用规则；本专家团负责具体制作流程。建议同时配置，避免把公司事实和项目资产约定重复写进每个成员。
