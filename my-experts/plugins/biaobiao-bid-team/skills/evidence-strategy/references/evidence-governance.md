# 证据治理规则

## 证据等级

| 等级 | 示例 | 可证明范围 |
|---|---|---|
| A 原始直接证据 | 证照原件、合同、检测报告、发票、验收证明 | 以可读原文和有效范围为限 |
| B 原始辅助证据 | 官网公示、官方查询结果、付款/履约辅助材料 | 支持或交叉验证，不自动替代招标指定形式 |
| C 经核验派生资料 | 已回查原件的台账、案例卡、历史标书章节 | 按核验日期和适用条件复用 |
| D 未核验线索 | 文件名、目录、OCR、旧模板、模型摘要 | 只能用于检索，不能证明事实 |
| E 外部观察 | 竞争对手标书、行业案例、公开文章 | 只用于结构或策略观察 |

## 已核验条件

必须同时满足：主体一致、内容可读、范围匹配、在有效期或满足招标时间要求、来源定位明确、没有未处置冲突。

## 常见证据链

- 资质：证照页 + 许可范围/附页 + 有效期/官方状态。
- 业绩：合同关键页 + 产品/范围页 + 金额页 + 签章页 + 招标指定的履约/发票/验收证明。
- 检测：报告封面 + 样品信息 + 检测依据 + 结果页 + 机构资质/签章（以招标要求为准）。
- 人员：身份证明 + 劳动/社保 + 资格证书 + 任职关系（以招标要求为准）。

证据链缺一项时不得自动降格为已满足，应说明当前能够证明什么、不能证明什么。

## 冲突处理

保留冲突双方的路径、原文、日期和影响项。不得通过重命名文件、删除旧记录或只保留有利版本来消除冲突。
