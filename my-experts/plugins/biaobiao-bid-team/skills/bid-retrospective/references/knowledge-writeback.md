# 知识回写映射

| 内容类型 | 目标位置 | 回写条件 |
|---|---|---|
| 最终投标文件 | `历史标书/{年份-项目名称}/` | 用户确认归档范围和权限 |
| 新资质/证照原件 | `素材经验库/01-资质证照/` | 原件可读、主体和有效性已核验 |
| 新业绩证据 | `素材经验库/02-业绩案例/` | 合同及招标所需证明链已核验 |
| 优质技术模块 | `素材经验库/03-技术方案模块/` | 清除项目专属事实，注明适用条件 |
| 商务模板 | `素材经验库/04-商务模板/` | 不含项目专属数据和报价 |
| 评分观察/规律 | `素材经验库/05-评分规律/` | 记录样本、反例、适用条件和证据强度 |
| 失分教训 | `素材经验库/06-失分教训/` | 有结果或评审证据，区分事实和推断 |
| 结果与复盘 | `复盘档案/{年份-项目名称}/` | 保留来源、版本和缺失字段 |

## 回写原则

- 原始证据与派生总结分开存放。
- 不覆盖原件；使用新文件和版本记录。
- 对索引修正保留旧值、修正值、依据和日期。
- 只回写经确认内容；假设和未经证实归因留在复盘的待验证区。
- 商业敏感内容继承原项目权限，不因进入经验库自动扩大可见范围。
