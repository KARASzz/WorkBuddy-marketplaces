# 样例说明

## haining-yada-ganghua-map.json

已验证的完整映射表（海宁亚大 · 港华燃气 PE 管材竞价项目，2026-09-07 实际投产使用）。

**成果**：31 个映射项全部命中，457 处图片引用 / 446 张唯一图片全部插入对应章节，
生成带图 Word 188.5 MB，验证图片数与源 docx 一致。

### 结构

```json
{
  "目标Markdown文件名.md": [
    ["样板中的 section 名", "目标md中的锚点标题", "图注前缀"]
  ]
}
```

### 复用方式

1. 如果是**同类项目**（燃气 PE 管材 / 同系列招标方），直接改文件名即可复用大部分映射；
2. 如果是**新项目**，把本文件当作映射表编写范式：
   - section 名 = 样板原文标题（用 `--list-sections` 查）
   - 锚点 = 新标书 Markdown 中的**纯标题文本**（不带 `###`、不带 `**`）
   - 图注前缀 = 生成 Word 时显示在图下方的说明，如"专利证书"、"2024年财务报表"

### 锚点填写铁律

| 错误写法 | 正确写法 |
|---|---|
| `"### 三-2、营业执照..."` | `"三-2、营业执照..."` |
| `"**维度①：企业综合实力**"` | `"维度①：企业综合实力"` |

脚本内部会剥离 `#` 和 `*`，映射表里**写纯文本**。写错会导致全部提示"锚点未找到"。

### 配套

映射表依赖的 `doc_sequence2.json`（31 sections 版本）是**已验证基线**，
由本轮实际投产使用。若重新解析 docx 得到不同 section 名（因标题判定模式差异），
以本基线为准，或用 `--list-sections` 核对后调整映射表。
