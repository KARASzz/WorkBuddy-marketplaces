# 招投标风险定级矩阵

所有风险结论同时记录影响、发生可能性和证据充分度，不得只凭关键词定级。

| 影响 | 判定标准 |
|---|---|
| 高 | 可能导致无效投标、废标、资格不通过、报价无效、重大扣分，或出现围串标/侵权重大线索 |
| 中 | 可能导致一般扣分、澄清补正、响应偏差、证明材料不足或履约承诺争议 |
| 低 | 不影响实质性响应的格式、导航、表述或可快速修正的问题 |

| 可能性 | 判定标准 |
|---|---|
| 高 | 原文有明确“必须/否决/无效/不得偏离”规则，且当前材料直接不满足 |
| 中 | 有规则依据但证据不完整、存在解释空间或只能确认疑似缺口 |
| 低 | 规则未明确、仅为惯例提示，或已有较充分响应证据 |

定级规则：

- 高影响 + 高可能性：高风险或废标级。
- 高影响 + 中可能性，或中影响 + 高可能性：中风险；列入人工复核优先项。
- 其余组合：低风险或提醒。
- ★、否决、强制条款未响应，报价超限，必要资质明确缺失：直接列为高风险/废标级。
- 围串标、侵权、违法类信号即使分值高，也只输出“高风险信号”，不得作成立认定。

证据充分度：

- A：有原文条款、页码/章节和待检材料原文，允许按矩阵定级。
- B：只有单侧材料或出处不完整，最高输出“疑似/建议复核”。
- C：只有关键词、模型推断或外部规则未核验，不得输出确定性高风险结论；标注“待核实”。

每条风险至少输出：风险项、来源、影响、可能性、证据等级、风险等级、证据片段、整改动作。
