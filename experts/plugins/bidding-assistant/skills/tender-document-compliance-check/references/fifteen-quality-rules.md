# BQ01-BQ15 标书质量审查与整改分流

## 一、统一输出口径

每项规则只能取 `pass`、`fail`、`insufficient_evidence`。`pass` 表示当前版本、当前证据范围内未发现异常，不等同“完全合规”。

每个 `fail` 必须记录：

- `rule_id`、`risk_level`；
- `physical_pdf_pages`：从 PDF 文件首页起算的物理页；
- `displayed_page_numbers`：页面上显示的页码，无页码写“无”；
- `section`、`anchor`、`evidence`；
- `expected`、`fix_instruction`、`retest_condition`、`repair_owner`。

无法取得最终物理页码时，任何规则均不得判 `pass`；先把当前版本交给 `word-document-processing` 生成或渲染最终版面。证据不足不得编造页码或目标，使用 `insufficient_evidence` 并转人工或补充输入。

## 二、十五项规则

| 编号 | 审查规则 | 通过证据 | 默认整改责任 |
|---|---|---|---|
| BQ01 | 资格、强制、评分、技术、商务、报价、附件要求均有实质应答 | 要求—应答矩阵无缺项 | `bid-document-generation` |
| BQ02 | 投标表述与招标原文一致；扩写未改变数值、条件、范围、责任 | 原文、投标锚点、差异说明 | `bid-document-generation` |
| BQ03 | 举证定位到材料名、明确图号/表号及章节 | 证据映射可唯一定位 | `bid-document-generation` |
| BQ04 | 章节、图、表、附件交叉引用均存在且唯一 | 引用源—目标解析结果 | `bid-document-generation` |
| BQ05 | 图表编号连续、无重号且与引用一致 | 最终版图表索引 | `word-document-processing` |
| BQ06 | 过程稿占位语义统一醒目；候选终稿无未关闭占位 | 占位扫描与当前状态 | 内容退编制；可见样式退 Word |
| BQ07 | 每个小节标题下有实质内容 | 标题—正文结构清单 | `bid-document-generation` |
| BQ08 | 按“提交版优先”处理敏感信息，必要披露有招标依据 | 敏感项、披露依据、处理结论 | 编制或人工 |
| BQ09 | 表格宽度合理、跨页表头重复、首行缩进 0、对齐网格 | 最终版逐表检查 | `word-document-processing` |
| BQ10 | 无异常空白页、孤行、标题与正文分离、图注分家 | 最终 PDF 逐页检查 | `word-document-processing` |
| BQ11 | 目录含正文及附件，页码准确，无旧条目 | 目录项—标题—实际页映射 | `word-document-processing` |
| BQ12 | 半角/全角、成对标点、空格使用正确，不误改型号代码 | 最终可见文本检查 | 内容退编制；可见格式退 Word |
| BQ13 | 关键承诺数字全文一致且达到招标下限 | 承诺台账与阈值比对 | `bid-document-generation` |
| BQ14 | 投标、有效期、交付、证照、授权等日期口径一致 | 日期台账及语义分类 | `bid-document-generation` |
| BQ15 | 需签章页形成逐页清单，主体、类型和页码明确 | 最终版签章页面清单 | 清单退编制；签章转人工 |

## 三、专项判定

### BQ01-BQ04：响应和引用

- “已响应”必须有实质内容，标题、空表或“详见”但目标不存在不算响应。
- BQ02 允许增加实现方法和证据说明，但不得把“不得”改为“原则上不”、把最低值降低或遗漏条件。
- BQ03 的“图号”采用 `图X-X`，表采用 `表X-X`；仅写文件名或“如下图”不通过。
- BQ04 对“见第X节、图X-X、表X-X、附件X”逐条解析；零目标或多目标均不通过。

### BQ05-BQ07：编号、占位和空标题

- BQ05 按最终可见顺序检查跳号、重号、图表类型错用及引用不一致；由 Word 技能修复落版。
- BQ06 过程稿占位语义应为 `【待补充|BQ06|事项|责任人|截止时间】`；候选终稿任何未关闭占位均为阻断项。
- BQ07 标题下只有占位、目录域、重复标题或无实质意义套话时视为空。

### BQ08：提交版优先脱敏

- 招标明确要求的身份证明、联系方式、账户或签章信息保留，并记录条款依据。
- 非必要身份证号、手机号、邮箱、住址和账户信息应脱敏。
- 无法判断是否为必要披露时不得擅自遮蔽，标记证据不足并转人工。

### BQ09-BQ12：最终可见版面

- 这些规则是 Word 技能的验收与修复要求，合规技能只记录问题，不写入或重排 DOCX。
- BQ09 逐表检查，不得仅抽查首页；记录表名和问题行/列锚点。
- BQ10 区分有意章节起页与异常空白页；图和图注、表题和表格不得跨页分家。
- BQ11 同时核对附件、实际页码和旧条目；目录页码与物理页码不强求相同，但必须指向正确显示页。
- BQ12 保留产品型号、文件编号、英文缩写和代码中的必要半角字符。

### BQ13-BQ15：承诺、日期和签章

- BQ13 至少覆盖金额、税率、交期、质保期、有效期、响应时限、人员数量和服务频次；记录单位、起算点和适用范围。
- BQ14 区分绝对日期与相对期限；不得把“合同签订后 180 日”误判为与投标日期冲突。
- BQ15 清单包含文件/章节、签章主体、签章类型、物理页、显示页码和人工状态。

## 四、风险分级

- P0：仅用于招标明确否决/强制条件、应答遗漏导致实质不响应、承诺低于阈值、候选终稿关键占位、要求签章缺失或禁止披露的敏感信息泄漏。
- P1：影响评分、证据可信度、定位、目录、图表、表格或分页质量的问题。
- P2：不改变含义的标点、空格和体验问题。
- `manual_review`：证据不足、真实信息缺失、脱敏依据不明确或需要实际签章。

## 五、整改分流与复验

生成 `bid_repair_plan.json`：

- `bid-document-generation`：BQ01-BQ04、BQ06 内容、BQ07、BQ08 已确定内容处理、BQ12 文字内容、BQ13-BQ14、BQ15 清单；
- `word-document-processing`：BQ05、BQ06 可见样式、BQ09-BQ11、BQ12 可见格式；
- `manual`：真实资料缺失、BQ08 依据不明、BQ15 实际签章。

整改目标不得覆盖原文件，命名 `_优化Vn.docx`。每轮 Word 生成新版本后重新渲染并全量复验 BQ01-BQ15，不能只复验命中项；自动整改最多两轮，仍有未关闭项时停止并转人工。
