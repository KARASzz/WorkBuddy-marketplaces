# 标书十五项编制自检与质量台账

## 一、职责边界

本规则用于组织业务内容、形成 Word 技能验收要求和提交独立评审，不在本技能中创建、修改或重排 DOCX。

- 本技能负责：应答、原文一致性、证据图号、交叉引用语义、占位状态、小节内容、脱敏决策、承诺、日期和签章目标。
- `word-document-processing` 负责：图表编号落版、占位可见样式、表格、分页、目录和可见文本格式；任何修复均输出新版本。
- 人工负责：补充真实材料、确认披露依据、签章和最终提交。

## 二、BQ01-BQ15 编制规则

| 编号 | 编制自检 | 生成侧动作 | Word 技能交接 |
|---|---|---|---|
| BQ01 | 应答完整性 | 将资格、强制、评分、技术、商务、报价和附件要求逐条映射到应答 | 无 |
| BQ02 | 与招标原文一致 | 保留要求原文与来源；允许扩写说明，不得改变数值、条件、范围或责任 | 无 |
| BQ03 | 举证具体到图号 | 每项证据写明材料名、`图X-X` 或 `表X-X`、对应章节 | 按既定索引落版编号 |
| BQ04 | 交叉引用存在 | 建立引用源—唯一目标表；缺失或重名目标均阻断 | 保持目标可定位 |
| BQ05 | 图表编号连续无重号 | 提供图表清单、所属章节和建议编号 | 检查并修复连续性、唯一性 |
| BQ06 | 占位统一醒目 | 过程稿统一使用规定语义；候选终稿未关闭数必须为 0 | 统一可见样式，不改占位语义 |
| BQ07 | 小节标题下有内容 | 每个小节关联实质内容；空标题或仅有占位不得通过 | 无 |
| BQ08 | 敏感信息脱敏 | 按“提交版优先”建立披露依据和脱敏决策 | 仅执行已确认的替换或遮蔽要求 |
| BQ09 | 表格格式 | 提供表格用途、表头、列含义、内容量和招标样式依据 | 检查宽度、表头重复、首行缩进 0、对齐网格 |
| BQ10 | 分页质量 | 标记不可拆分的标题、图注和签章块 | 检查空白页、孤行、图注分家 |
| BQ11 | 目录完整准确 | 提供章节、附件和唯一定位键，清除旧目录数据 | 生成/更新目录并核对真实页码 |
| BQ12 | 标点文字规范 | 统一中文语境中的标点、成对符号和无意义空格，不改型号与代码 | 检查最终可见文本的半角、成对和空格 |
| BQ13 | 关键承诺数字一致且达标 | 建立全文承诺台账并与招标下限逐项比较 | 无 |
| BQ14 | 日期一致 | 建立日期台账，区分投标日期、有效期、交付期、证照期和授权期 | 无 |
| BQ15 | 需签章页面清单 | 按文件/章节/签章主体/签章类型建立目标清单 | 最终版面生成后提供实际页码供人工签章 |

## 三、关键口径

### 1. 原文与证据

- 每条要求保存 `requirement_id`、原文、来源章节和来源页。
- 扩写只能解释如何满足要求，不得降低参数、缩小范围、改变起算点或删除限制条件。
- 证据引用不得只写“见附件”或“见下图”；必须写材料名、图号或表号、章节。
- 所有“见第X节、见图X-X、见表X-X、见附件X”必须解析到一个且仅一个目标。

### 2. 占位与空章节

- 过程稿占位语义固定为 `【待补充|BQ06|事项|责任人|截止时间】`。
- 仅有标题、占位、目录域文本或少量无实质含义套话的小节标记为未完成。
- `candidate_for_compliance` 和后续状态不得存在未关闭占位；缺真实值时保持 `draft_blocked`。

### 3. 提交版优先脱敏

- 招标明确要求的身份证明、联系方式、银行账户、授权或签章信息保留，并记录招标依据。
- 非必要身份证号、手机号、邮箱、住址、账户信息标记脱敏；保留必要的主体识别信息。
- 招标依据不明确、材料同时服务于公开版和提交版或遮蔽会影响证明效力时转人工，不自行决定。

### 4. 承诺与日期

- 承诺台账至少覆盖金额、税率、交期、质保期、有效期、响应时限、人员数量和服务频次。
- 每个数值记录单位、起算点、适用范围、招标阈值、投标值和全文出现位置。
- 日期台账区分日历日期、相对期限和有效期；同一含义出现冲突或低于招标要求时阻断。

## 四、`bid_quality_manifest.json`

最低结构：

```json
{
  "schema_version": "1.0",
  "project": {"name": "", "tender_no": ""},
  "bid_version": {"document_path": "", "document_sha256": "", "state": "draft_blocked"},
  "requirements": [],
  "evidence_refs": [],
  "cross_references": [],
  "figures_tables": [],
  "placeholders": [],
  "section_content": [],
  "sensitive_items": [],
  "commitments": [],
  "dates": [],
  "signature_targets": [],
  "word_acceptance_requests": [],
  "checks": [{"rule_id": "BQ01", "status": "pass|fail|insufficient_evidence", "evidence": []}],
  "blockers": []
}
```

`checks` 必须且仅包含 BQ01-BQ15。`pass` 必须有证据；`fail` 和 `insufficient_evidence` 必须给出责任方、修复动作和复验条件。质量台账绑定当前文件哈希，不得跨版本复用。

## 五、状态门禁

- `draft_blocked`：存在 P0、未关闭占位、缺真实材料、冲突承诺/日期或无法确定脱敏依据。
- `candidate_for_compliance`：业务自检无阻断，Word 技能已生成新版本，可进入独立审查；不等同可提交。
- 独立审查发现问题后，按 `bid_repair_plan.json` 定点修复；不得覆盖原文件，目标名使用 `_优化Vn.docx`。
