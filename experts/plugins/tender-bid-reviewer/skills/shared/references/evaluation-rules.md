# 评标办法解析与模拟规则

## 1. 先还原文件模型，不使用经验公式

从评标办法逐项抽取：

```text
评标方法｜资格审查主体与标准（如明示）｜符合性要求
评分项｜类别｜分值/权重｜分档｜计分条件｜单项上限
所需证明｜价格基准定义｜价格公式｜政策调整｜算术修正
保留小数/四舍五入｜有效报价范围｜并列处理｜否决规则
```

任何字段未出现，都写为“文件未见明确规则”，而不是按行业惯例补全。

## 2. 评分项分类

| 类别 | 能否直接计算 | 正确处理 |
|---|---|---|
| 资格条件 | 否 | 作为前置核验，不并入评分 |
| 符合性/实质性要求 | 否 | 作为通过/风险核验，不并入评分 |
| 有固定条件与分值的客观项 | 可以，前提是证据完整 | 显示每一步计算和上限 |
| 价格项 | 仅按文件明示公式 | 显示参与计算的有效报价和假设 |
| 主观方案、理解、完善性 | 不应假装可精确计算 | 输出分档依据、材料覆盖度、需人工判断点 |

## 3. 客观评分检查

对于“每提供 1 项得 X 分，最高 Y 分”等规则：

1. 确认计数对象和条件；
2. 检查每项证据的时间、类型、金额、主体、证明材料要求；
3. 计算符合数量 × 单项分；
4. 应用上限、互斥、重复计分和文件明示的取整规则；
5. 列出不计分或待核验的材料及原因。

## 4. 价格项

- 先确认哪些投标报价可以进入计算，是否需政策价格扣除或算术修正。
- 只使用招标文件明示的基准价、公式、封顶、舍入和异常报价处理规则。
- 若用户仅提供一家报价，无法计算依赖其他有效报价的公式，必须说明不可计算。
- 对报价合理性，仅列出文件要求的说明/证明与可能需要人工复核的因素；不能自行断言低于成本、恶意报价或串通。

## 5. 模拟评审与多家比较

模拟结果的标题必须含“模拟/文件内推演”，并写明：

- 仅基于用户提供且已解析的材料；
- 不等同于实际评标委员会结论；
- 主观项不保证实际得分；
- 未提供材料保持“未知/待核验”，不能为比较方便而记零分；
- 多家材料须使用同一规则和证据标准。

严禁根据关系、评委偏好、未公开竞争对手信息、报价推测或其他不正当信息给出策略。
