# 规则适用与法规边界

本文件只提供审阅时的边界提示，不是法律意见，也不是穷尽性法规库。处理具体项目时，必须先确认项目类型、地区、行业规则和招标/采购文件的明示条款；法规有更新时以届时有效的官方文本为准。

## 1. 先区分适用体系

| 场景 | 审阅重点 | 不可混用的典型规则 |
|---|---|---|
| 政府采购货物/服务 | 政府采购法、实施条例、财政部令87号及项目文件 | 资格条件与综合评分因素、价格基准价/公式、澄清和算术修正规则须按政府采购文件及规则处理 |
| 依法必须招标或其他招标投标项目 | 招标投标法、实施条例、行业/地区规则及项目文件 | 否决投标情形、投标保证金、澄清修改和评标标准按该体系与文件处理 |
| 企业/非强制项目 | 合同、公司制度、项目文件与双方约定 | 不能将法定招标/政府采购的程序性结论直接套入 |
| 不明 | 先提示适用规则未确认 | 仅作文件内一致性审阅，避免法律定性 |

## 2. 审阅时可用的官方规则提示

- 《招标投标法》要求评标按招标文件确定的标准和方法进行；招标文件的澄清/修改是组成部分。依法必须招标项目的时限、异议和保证金等规则见其与实施条例。
- 《招标投标法实施条例》第51条列举评标委员会应否决投标的情形，包括签署盖章、联合体协议、资格、重复投标/报价、低于成本或高于最高限价、未实质性响应、串通/弄虚作假/行贿等；具体认定仍须结合项目适用规则和事实。
- 政府采购货物服务项目中，财政部令87号要求对不允许偏离的实质性要求以醒目方式标明；符合性审查审查是否满足实质性要求。该办法还规定某些含义不明、前后不一致或明显文字/计算错误可书面澄清、说明或补正，且不得超出或改变投标文件的实质性内容。
- 政府采购综合评分法中，资格条件不得作为评审因素；评审因素、权重和价格计算应以采购文件明示内容为准。不得把工程或其他项目常见的平均价/去极值/下浮系数公式套用到未明示该公式的政府采购项目。
- 《民法典》合同编已取代原《合同法》相关制度。任何旧文献中的“适用合同法”表述均应改为“结合届时有效的民法典、特别法和合同约定确认”。

## 3. 输出法律风险的正确方式

优先用以下句式，而非直接裁决：

- “招标文件第 X 条将此项列为资格条件/不允许偏离要求；当前提供材料未见对应证据，存在高风险，建议在截标前按文件和适用规则核验。”
- “该差异是否可澄清或补正，取决于项目适用规则、招标文件及其是否改变实质内容；本专家不作最终程序认定。”
- “文件之间存在冲突且未见优先级约定，建议在文件规定的正式渠道和时限内提出澄清。”
