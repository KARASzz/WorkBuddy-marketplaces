# 投标文件预审规则

## 1. 预审的正确顺序

```text
最新招标侧规则与补遗
        ↓
资格与文件提交要求
        ↓
投标响应和证明材料
        ↓
资格 / 符合性 / 完整性 / 一致性 / 专项核验
```

不能从投标文件反推规则，更不能因投标文件写了“满足”就视为满足。

## 2. 审阅维度

| 维度 | 核验对象 | 典型输出 |
|---|---|---|
| 文件完整性 | 必交格式、附件、份数、电子/纸质要求、提交材料 | 缺失材料清单 |
| 资格表面符合性 | 主体、资质、许可、人员、业绩、财务、信用、联合体/分包 | 要求—材料—待核验矩阵 |
| 符合性与偏差 | 实质性技术/商务/报价/有效期/保证金/签署要求 | 高风险和偏差表 |
| 技术响应 | 参数、性能、标准、实施方案、验收、服务、证明 | 参数—响应—证据表 |
| 商务响应 | 工期/交付、付款、质保、合同、承诺、分包 | 商务响应与附加条件表 |
| 报价一致性 | 单价、数量、合价、总价、税、报价口径、有效期 | 算术与逻辑检查表 |
| 内部一致性 | 项目名称、标段、主体、日期、金额、人员、设备、参数、业绩 | 冲突清单 |

## 3. 资格与证明材料

### 检查原则

- 只对照招标文件要求的对象、时间、范围、数量、等级和证明形式。
- 材料“存在”不等于“符合”：例如证书须核对主体、有效期、等级、项目/标段适配性；业绩须核对时间、类型、规模和招标文件要求的证明链。
- 外部查询结果、原件状态、签章真实性、社保/信用/财务真实性等，未具备合法可验证材料时写为 `待核验`，不要凭视觉判断为真伪。
- 联合体、分包和授权只能按招标文件与适用规则确认；不能假设所有项目允许或禁止。

## 4. 响应与偏差

### 技术参数

每行至少比较：`招标指标｜比较对象｜操作符/范围｜数值和单位｜是否实质性/评分项｜投标响应｜证据型号/测试条件｜结论`。

- 同一数字但单位、型号、测试条件或范围不同，不能直接判满足。
- “完全响应”“无偏离”必须有表格/方案/证明支持；只用笼统承诺时标为待核验。
- 只在文件明示或可从上下文确定时称“实质性要求”。

### 商务与合同

核对投标函、商务偏离表、承诺函、报价表、合同响应和技术方案中涉及交付、付款、验收、质保、违约、分包、保密等表述。发现与招标文件抵触或新增条件时，标记为高风险或待澄清；不要建议通过隐蔽文字规避条件。

## 5. 一致性核验的字段字典

优先抽取并跨文档比对：

```text
项目名称｜项目编号｜标段｜投标人全称/统一社会信用代码｜法定代表人/授权人
报价币种/含税口径/总价/分项价｜工期/交付/服务期｜投标有效期
项目负责人/关键人员｜产品品牌/型号/参数｜业绩名称/合同主体/金额/日期
版本号/补遗编号/日期
```

出现差异时，列出双方原文和位置，不能自行选择其中一个为正确版本。

## 6. 预审报告中必须避免的错误

- “任何错别字、页码、装订问题都导致废标”。仅当文件或适用规则明确，或该问题影响实质内容/身份/密封/递交时，才提示相应风险。
- “报价前后不一致必然无效”。要先检查项目适用规则、招标文件和是否存在允许的算术修正/澄清机制。
- “未显示某材料即材料不存在”。正确说法是“当前已解析材料中未见”。
- “资质将覆盖履约全周期”。除非项目文件明确该口径，否则按投标截止日/文件要求核验并提示后续履约需复核。
