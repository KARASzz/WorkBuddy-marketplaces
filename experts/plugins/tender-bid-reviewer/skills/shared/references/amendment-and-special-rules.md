# 补遗、版本与专项审阅规则

## 1. 版本控制

建立版本台账：`文件名｜角色｜编号｜发布日期/版本号｜来源（如可见）｜解析状态｜与何文件比较`。

补遗、澄清、答疑、修改版和重发附件要分别登记。文件没有明示优先级时，不能以“后发一定优先”作为结论；应报告冲突并建议按项目规定的正式渠道澄清。

## 2. 补遗影响分析

每一条修改都做两层分析：

1. **直接影响**：被替换/新增/删除的规则或数值本身；
2. **关联影响**：可能需要同步修改的投标函、封面、资格文件、响应表、产品证据、技术方案、报价、日程、合同响应和内部任务安排。

输出：

| 补遗/版本 | 原文要求 | 修改内容 | 影响类别 | 受影响投标材料 | 建议动作 | 证据位置 |
|---|---|---|---|---|---|---|

## 3. 技术参数专项

参数必须保留原始比较语义：

| 字段 | 说明 |
|---|---|
| 指标与对象 | 例如设备、模块、系统或服务指标 |
| 条件/操作符 | ≥、≤、=、范围、兼容、必须具备等 |
| 数值与单位 | 不丢失小数、单位、测试工况 |
| 性质 | 实质性、一般、评分或文件未明示 |
| 投标响应 | 型号、数值、承诺、方案位置 |
| 证明 | 数据手册、检测报告、授权、案例等 |

不把不同型号、不同工况、不同单位或“类似”描述自动视为等同。

## 4. 商务合同专项

审阅重点：价格及税费、付款/条件、保证金、交付/工期、验收、质保、变更、违约与责任限制、保险、分包、保密/数据、知识产权、争议解决。

输出应为“文件条款—业务影响—需确认事项—可行应对”，而不是断言条款有效性或提供正式法律结论。涉及重大法律利益时建议由项目法务/律师复核。

## 5. 报价与工程量清单专项

检查顺序：

1. 报价范围是否覆盖文件定义的工作、服务、税费和附件要求；
2. 单位、数量、单价、合价、总价、币种、税率、暂估/暂列金额是否在文件内一致；
3. 是否存在文件明示的不可竞争项、修正规则或有效报价规则；
4. 报价是否与工期、资源、技术方案和合同付款口径存在明显内部冲突。

未收到完整清单、图纸、范围说明或成本资料时，不能给出“无漏项”“报价合理”“低于成本”等结论。
