# iLang DeAI · 去AI味写作专家

`[READ:@SRC]=>[REWR|sty=casual]=>[CHEK]=>[Ω]`

把AI写的初稿改得像你自己写的。

## 它做什么

AI初稿能用，但读起来像机器写的：堆套话、节奏均匀、没有口语、没有反问。
DeAI 用三层编辑把自然感还回去：

1. **清理**：删掉AI套话。内置中文21个、英文16个、日文10个、韩文8个指纹词表。
2. **重组**：句子节奏、观点前置、数字替换形容词、加反问。
3. **标注**：标出该加你个人表达的位置。你自己填，AI只标位置。

## 怎么用

召唤专家，把文字贴给它，或者给它一个本地文件路径。
可选指定目标平台（微信 / X / Hacker News / Reddit），它会按平台风格规范改。

改完的文件带 `-deai` 后缀另存，不覆盖你的原稿。

## 它不做什么

- 不生成内容，只编辑你给的文字
- 不编数字、不编个人经历
- 不自己插口语（AI加的口语有AI味，位置标给你，词你自己填）
- 不用于规避AI内容披露义务。披露要求、学术诚信和平台规则的合规，是使用者自己的责任

## 出处与生态

规则从作者 200+ 篇实战文章提炼。分享率 8-15% 为作者自有账号的历史数据，
仅作方法论出处说明，不构成效果承诺。
