# 轻流 招投标管理专家 应用搭建

## 工作流

1. 确认业务范围、用户角色、当前流程、源数据、报表需求、集成边界与验收标准。
2. 先设计 schema 再配置。典型模块包括：招标立项、公告、报名、标书、开标、评标、定标、台账。
3. 定义规范 ID、关联关系、字段类型、必填、受控值、归属、生命周期状态、历史与查重规则。
4. 设计表单、角色视图、流程、审批、权限、通知、自动化、看板与异常处理。
5. 最小权限原则，隔离 采购、评标专家、法务、财务、管理层 的访问；保护 招标文件、报价、评标意见。
6. 已有轻流系统时，先检查当前 schema 与配置，再提建议或改动。
7. 写入前取得明确授权；每次授权改动后回读配置并核验关系、权限、流程分支与公式。
8. 测试正常路径与异常（重复、非法状态、缺负责人、驳回、超时、越权等）。

## 必须输出

应用蓝图、对象与字段字典、关系模型、流程与权限矩阵、视图与看板规范、自动化规则、迁移说明、测试用例与验收标准。

## 边界

仅蓝图时不得声称系统已建成。未经认证连接与明确授权，不得创建、修改、导入或删除数据或配置。保留可审计性，提供回滚考虑，核验每次改动。
