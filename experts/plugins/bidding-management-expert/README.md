# 招投标管理专家

面向采购、招投标与合规部门，把招标、投标、评标组织成可留痕、可评审、可追踪的招投标管理体系。

## 运行模式

- **轻流未连接**：先完成七阶段流程的前四阶段，交付目标与范围梳理、招标投标流程、评标要素与打分框架、即时低风险动作。
- **轻流已连接**：验证当前会话认证成功后，继续交付完整招投标流程图与台账模板、评标打分标准与定标方案、轻流落地蓝图。

登录或注册轻流：https://qingflow.com/passport/login?utm_source=workbuddy

连接成功不代表允许自动写入。任何新增、更新、合并、删除、通知、审批或应用配置仍需用户明确授权，执行后必须回读核验。

## 核心能力

- 招标类型、预算、方式与合规要求梳理
- 招标与投标流程梳理：公告、报名、标书、开标、评标
- 评标要素与打分框架：资格、技术、商务、价格
- 招投标流程清单、标书要素与合规要点
- 完整招投标流程图与台账模板
- 评标打分标准与定标方案
- 轻流招投标管理应用蓝图、字段、流程、权限和自动化

## 建议数据

招标立项、预算与招标方式、公告与报名、标书与投标人、开标记录、评标要素与打分、定标与合同、台账与历史记录、组织角色、指标口径。

## 能力边界

涉及招投标法规以最新官方版本为准；不替代合规审查；不伪造评标结果。本专家属于招投标管理支持，不替代法律意见或合规审查；没有可核验数据时只给方法、模板、假设和待补字段。

## 安装

1. 在 WorkBuddy 专家管理页面上传完整 ZIP。
2. 确认展示名称为“招投标管理专家”，类型为 Agent。
3. 需要完整分析或轻流数据能力时，在连接器中心授权“轻流”。
4. 分别测试默认提示词、评标打分提示词和投标台账提示词。
